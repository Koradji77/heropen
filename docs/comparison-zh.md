# 本地 AI 记忆方案技术对比（行业综述，2026-08）

> 本文客观梳理当前主流「本地优先 AI 记忆」方案的技术共性、选型维度与差异点。只列技术事实，不评价优劣，供读者自行判断。

## 共同的技术底座

主流本地记忆方案普遍采用：

- **SQLite** 作为存储引擎（单机文件，零运维）；
- **MCP（Model Context Protocol）** 作为 agent 接入标准；
- **向量 + 全文（FTS）** 混合检索；
- **零外联默认**：记忆不出本机。

这意味着「本地优先」本身已不是差异点，真正的区别在于**产品化分层、交互侧能力、安装与依赖**。

## 差异点小结（技术事实）

- **Cortex** 把「零外联」从声明推进到**运行时强制**（明文注入拒绝、per-operation HMAC、deny-by-default 的 MCP 能力策略、密钥轮换前向保密），并在 v2.3 规划移动端与多模态记忆——它抢的是「跨端 / 浏览器 / 移动记忆」的表达位。
- **Memanto** 推动 **OKF（Open Knowledge Format）** 作为记忆的开放、可移植格式，强调「数据可带走」；其早期版本曾因默认 `0.0.0.0` 绑定导致未授权访问，后续版本已修复。
- **heropen** 的差异在**产品化分层**（私有 / 共享域）、**交互侧时间感知**、以及**零依赖的安装面**。

## 给选型者的建议

如果你看重「能跑起来最简单」→ 看安装前置与依赖；如果你看重「数据可审计、可带走」→ 看记忆格式与导出能力；如果你看重「不暴露到网络」→ 看安全默认值与运行时约束。
