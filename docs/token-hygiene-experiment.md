# 记忆卫生与 token 占用：一个克制的小实验

> 目的：用可复现的方法说明「选择性记忆」为何比「全量历史」更省 token。本实验为方法演示，数字为示例估算，非基准跑分；测试条件已标注。

## 测试条件（声明）

- 上下文以 token 计；中文粗略估算约 1.5 字 / token。
- 单条记忆平均 80 字 ≈ 53 token（含少量元数据）。
- 场景：agent 每次对话开场需注入「相关记忆」。

## 方法

- **全量注入**：把全部 N 条记忆原文塞入开场 context。
- **选择性注入**（heropen 当前策略）：向量 / 全文检索取 top-k（k=5）+ 记忆卫生标记（重复 / 过期只标不删，不额外占用）；未命中不注入。

## 示例估算（N = 200 条记忆）

| 策略 | 注入条数 | 估算 token | 相对全量 |
|---|---|---|---|
| 全量历史 | 200 | ~10,600 | 100% |
| 选择性 top-5 | 5 | ~265 | ~2.5% |

## 结论（克制表述）

- 全量历史在 token 占用上是选择性策略的约 40×；这与公开研究中「全量历史反而低于无记忆基线」的观察方向一致——塞得越多，噪声越大、信号越稀释。
- heropen 的「存得准、自动裁剪呈现」比「存得多」更符合本地零成本约束。
- 本实验**不发布任何分数榜单**，仅说明产品设计取舍；若需可复现数据，请按上述测试条件自行测算。
